Zichen Liu

I am a Ph.D. student in Computer Science at Arizona State University, advised by Prof. Xusheng Xiao (expected graduation: May 2028).

Previously, I obtained my M.S. in ECE from the University of Washington and my B.S. in Physics from Lanzhou University (Cuiying Honors College).

My research interests lie at the intersection of Software Engineering, Program Analysis, and Machine Learning, with a focus on software security (program analysis and automated vulnerability repair), social-engineering security, and the security of LLM-based systems. I combine program analysis with machine learning to make software behavior legible and to build defenses on top of it — describing how mobile apps use sensitive data (AppBDS, BinCtx), detecting online scams while a conversation is still unfolding (EARS), and structuring security knowledge to guide automated vulnerability repair.

Publications
Demystifying Scam Playbooks: Psychological Techniques, Scenario Taxonomy, and Conversation-Aware Detection
Shang Ma, Chen Yanai, Avichai Ben, Zichen Liu, Yanfang Ye, Xusheng Xiao
Under review at IEEE Symposium on Security and Privacy (S&P), 2027
arXiv

We derive a hierarchical taxonomy of 18 scam scenarios from 102K real-world incident reports, then transfer that scenario knowledge to bank customer-service conversations with EARS (Early Anti-scam Recognition System), which withholds judgment on benign turns and commits to a scam scenario as soon as diagnostic evidence appears, so a warning can be raised while the call is still going.

AppBDS: LLM-Powered Description Synthesis for Sensitive Behaviors in Mobile Apps
Zichen Liu, Xusheng Xiao
IEEE/ACM International Conference on Automated Software Engineering (ASE), 2025
paper / code

We combine static program analysis with LLMs to automatically generate detailed descriptions of how Android apps use sensitive user data, addressing the transparency gap in permission usage.

BinCtx: Multi-Modal Representation Learning for Robust Android App Behavior Detection
Zichen Liu, Shao Yang, Xusheng Xiao
arXiv preprint, 2025
arXiv

BinCtx fuses a bytecode-as-image view, manifest/URL context, and third-party-library usage along call paths to detect malware and undesired app behaviors (94.73% macro-F1 on ~17K apps), and stays robust under commercial code obfuscation and adversarial samples.

Adversarial Demonstration Attacks on Large Language Models
Jiongxiao Wang*, Zichen Liu*, Keun Hee Park, Zhuojun Jiang, Zhaoheng Zheng, Zhuofeng Wu, Muhao Chen, Chaowei Xiao (*equal contribution)
arXiv preprint, 2023
arXiv

advICL shows that a black-box attacker who perturbs only the in-context demonstrations, leaving the query untouched, can steer LLMs into targeted misclassifications; Transferable-advICL makes one adversarial demonstration transfer to unseen inputs.

Tracklet-based Multi-camera Multiple People Tracking
Cheng-Yen Yang*, Aotian Zheng*, Zichen Liu, Yujie Li, Jenq-Neng Hwang
ICCV 2021 Multi-camera Multiple People Tracking Workshop (challenge entry, winner talk)
presentation

3rd place in the MMP-Tracking Challenge. We built a multi-camera tracking system whose cross-camera tracklet association extends a single-camera tracker (FairMOT) across views.
